## API Reference
Ejemplo de algunos Endpoints que hice...

- **Get random weapon**

```http
  GET /api/weaponsDS
```


- **Get random weapon image**

```http
  GET /api/weaponsDS/imagen
```

- **Get weapon image by Id**

```http
  GET /api/weaponsDS/imagen/id/{id}
```
